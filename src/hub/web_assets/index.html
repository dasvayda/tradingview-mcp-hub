TradingView Desktop 연동

이 페이지는 차트 앱이 debug 모드로 켜져 있는지 확인함. 연결되면 Cursor MCP가 백테스트 숫자를 읽을 수 있음.

확인 중...

-

1. Debug 모드로 앱 실행

그냥 아이콘으로 연 TradingView는 연결할 수 없음. 한 번 종료한 뒤, debug 포트(9222)를 열고 다시 실행해야 함.

  1. TradingView를 완전히 종료함.
  2. 아래 스크립트를 PowerShell에서 실행함. (기존 앱을 종료한 뒤 debug로 다시 켬)
  3. 이 페이지에서 다시 확인을 누름.
  4. 상태가 "연결됨"이면 Cursor 채팅에서 TradingView MCP를 켜면 됨.
powershell -ExecutionPolicy Bypass -File scripts\launch_tv_debug.ps1

2. 차트에 붙은 기존 전략은 닫기

허브가 새 전략을 차트에 못 붙이면, 에디터에 열려 있던 기존 파인 파일을 저장으로 덮어쓸 수 있음. Strategy Tester는 차트에 이미 있는 전략 숫자를 읽음.

  1. 레이아웃 범례에서 기존 Strategy를 X로 제거함. 눈 아이콘만 끄면 Tester가 다시 켤 수 있음.
  2. 파인 에디터는 Open → New → Strategy 로 빈 스크립트를 연 뒤 허브를 실행함. 저장된 Daily MA 같은 파일을 연 채로 두면 Save가 그 파일을 덮어씀.
  3. 허브는 이름에 Strategy가 들어간 스터디를 자동으로 제거하려고 함 (tv.clear_existing_strategies).

3. 설명 / 링크

  • tradesdontlie/tradingview-mcp — 이 허브가 쓰는 MCP (star 가장 많음)
  • Quick Start — Desktop을 debug 포트로 켜는 공식 안내
  • Chrome Remote Debugging — `--remote-debugging-port` 가 하는 일

Microsoft Store 설치본은 debug 포트가 막히는 경우가 있음. 그때는 MCP 도구 tv_launch 가 로컬 복사본으로 실행하는 우회를 씀.

4. Cursor MCP

프로젝트 파일 .cursor/mcp.json 에 tradingview 서버가 들어가 있음. Cursor 설정에서 해당 MCP를 활성화한 뒤 채팅을 새로고침하면 됨.

테스트용 저장 레이아웃이 있으면 config/default.yaml 의 layout 에 이름을 넣음. 비우면 지금 열린 차트를 쓰고, 종목은 config 값으로 다시 맞춤.
